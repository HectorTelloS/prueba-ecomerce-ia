# Changelog

Todos los cambios notables de este proyecto se documentarán en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/), y este proyecto adhiere a [SemVer](https://semver.org/lang/es/).

## [0.1.0] - 2026-06-30

### Añadido
- Estructura inicial de e-commerce React con Vite, React Router, Context API, servicios Fetch y SCSS.
- Catálogo de productos conectado a la API pública de EscuelaJS/Platzi con estados de carga, éxito y error.
- Carrito persistente en `localStorage` con agregado, eliminación, vaciado y cálculo de totales.
- Vistas de inicio, carrito y detalle de producto.
- Pruebas iniciales para servicios, carrito, tarjeta de producto y página de inicio siguiendo TDD.
- Documentación de arquitectura inicial en `docs/application-architecture.md`.
